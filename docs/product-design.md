# 产品设计文档 · DSH 技能管理插件

> 版本：v0.1 ｜ 日期：2026-11-02 ｜ 状态：已确认
> 用途：确定本版本"做什么 / 暂时不做什么"，作为技术设计与实现开发的统一依据（施工图）。

## 1. 一句话定位

给 DeepSeek Harness（DSH）桌面端加一个左侧栏入口「技能管理」：在一页内从 SkillHub / SkillsMP / GitHub 三个平台搜索并一键安装技能，同时查看、卸载本机已安装的技能。解决两个真实痛点——装技能要记命令、卸载技能要手动翻目录删文件夹。

## 2. 核心用户路径（主流程）

1. 用户点击左侧栏「技能管理」，主区域打开管理页（默认停在「已安装」视角的同一页）。
2. 在搜索框输入关键词（如 "pdf"），切换平台页签（SkillHub / SkillsMP / GitHub），看到结果卡片。
3. 点卡片上的「安装」→ 按钮进入"安装中"，成功后卡片标记"已安装"，下方已安装列表实时新增该技能。
4. 在已安装列表里点「卸载」→ 弹出确认（显示技能名与路径）→ 确认后目录被删除，列表移除该行。
5. GitHub 页签额外支持"按仓库安装"：粘贴 `owner/repo` 或仓库 URL → 扫描出仓库内所有技能目录 → 选择其一安装。

## 3. 本版本功能清单（MVP）

| 功能 | 说明 | 优先级 |
|---|---|---|
| 侧边栏入口 + 主面板 | 左侧栏出现带图标的一行，选中后主区域渲染管理页，可切回会话 | 必须 |
| 已安装技能列表 | 扫描 `~/.dsh/skills` 与 `~/.agents/skills`，显示名称、描述、来源目录、路径、文件数 | 必须 |
| 卸载技能 | 二次确认；只允许删除受管根目录内的条目；目录与单文件 `.md` 技能都支持 | 必须 |
| SkillHub 搜索 + 安装 | 走 `api.skillhub.cn` 搜索接口，zip 包下载安装 | 必须 |
| SkillsMP 搜索 + 安装 | 走 `skillsmp.com/api/v1` 搜索，按结果里的 GitHub 地址安装 | 必须 |
| GitHub 按仓库安装 | 支持 `owner/repo`、`github.com/.../tree/<branch>/<path>`、`.../blob/.../SKILL.md`；扫描仓库内技能目录 | 必须 |
| 安装通用校验 | 必须含 `SKILL.md`，frontmatter 有 `name`（kebab-case）与 `description`；不合格直接拒绝并说明原因 | 必须 |
| 同名冲突处理 | 目标目录已存在时返回冲突，由用户在界面确认"覆盖安装" | 必须 |
| 设置：可选凭证 | 页内设置区填 GitHub Token（提高 API 额度）与 SkillsMP API Key（提高搜索额度），保存在本机 `~/.dsh/skill-manager/config.json` | 必须 |
| 错误提示 | 网络失败、限流（429）、平台返回异常、路径非法，均以页面内提示条说明原因 | 必须 |
| 中英文案 | 跟随 DSH 语言（zh / en），中英字典内置 | 必须 |

## 4. 明确不做的事（推迟清单）

- 不做技能的编辑、新建、启用/禁用开关（DSH 通过 SKILL.md frontmatter 控制，改文件即生效，另开需求再说）。
- 不做版本更新检测 / 一键升级（本期只保证"装"和"卸"）。
- 不做批量安装、批量卸载。
- 不做评分、评论、收藏、下载排行等社区功能。
- 不做私有仓库鉴权（只支持公开仓库 + 可选公开 Token）。
- 不覆盖 TUI / headless 场景的 UI（插件只挂 web 客户端）。
- 不管理 DSH 内置、插件内嵌（runtime provider）的技能，只管理本机两个用户级目录。

## 5. 边界条件与约束

- **删除安全**：卸载目标必须解析后仍在受管根目录内（拒绝 `..`、符号链接逃逸、根目录本身）；不存在则报错而非静默成功。
- **安装落点**：统一安装到 `~/.dsh/skills/<skill-name>`；`~/.agents/skills` 只读展示（可卸载但不作为安装目标），避免破坏其他 AI 工具的约定目录。
- **原子写入**：先写入暂存目录，校验通过后再替换目标目录；失败清理暂存，不留下半成品。
- **网络**：所有外部请求带超时（默认 20s，下载 60s）；GitHub 匿名 60 次/小时限流要给出可读提示，不能只抛 403。
- **无需重启**：安装/卸载后 DSH 的技能目录监听会自动刷新目录，页面只需重新拉取列表。
- **不写系统目录**：不触碰 `~/.dsh/skills/.system`（DSH 保留目录）。
- **凭证**：Token/Key 只落本机配置文件，不写日志、不回显完整值（界面只显示是否已配置）。

## 6. 验收要点

- [ ] 重启 DSH 桌面端后，左侧栏出现「技能管理」入口，点击后主区域显示管理页，不报错。
- [ ] 已安装列表正确列出两个目录下的技能（含 `stable-delivery-workflow` 这类已有技能）。
- [ ] SkillHub 搜索 "pdf" 返回结果，安装其中一个后 `~/.dsh/skills` 出现该技能目录，列表刷新显示已安装。
- [ ] SkillsMP 搜索返回结果（匿名额度内），安装后目录结构正确。
- [ ] GitHub 输入 `anthropics/skills` 能列出仓库内技能目录，安装其中一个成功。
- [ ] 卸载一个测试技能，确认弹窗出现，确认后目录被删除且列表移除；取消则不删除。
- [ ] 尝试卸载不存在的技能 / 构造越界路径，被拒绝且有提示。
- [ ] 缺 `SKILL.md` 或 frontmatter 非法的包被拒绝安装，提示原因。
- [ ] 同名技能二次安装时提示冲突，确认可覆盖。
- [ ] 断网 / 错误关键词时页面给出可读错误提示，不白屏。
