# 人工验收清单 · DSH 技能管理插件

> 原则：AI 自测通过 ≠ 无 Bug；验收单只能由人签。
> 使用：每个版本交付前逐项走查，全部通过后再进入下一轮迭代。

## 0. 准备

- 插件已装入桌面端 profile（`dsh plugin --profile desktop add link:<本目录>`，已执行）。
- **请从开始菜单或桌面快捷方式正常启动一次 DeepSeek Harness**（不要从被安全策略约束的终端启动，否则宿主进程可能起不来）。
- 验收过程中如要清理：`dsh plugin --profile desktop remove dsh-skill-manager` 后重启。

## 1. 冒烟测试（能不能跑）

- [ ] 重启后应用正常启动，能进会话，无报错弹窗
- [ ] 左侧栏（在「自动化任务」下方）出现「技能管理」入口，图标与文字正常
- [ ] 点击入口后主区域渲染管理页，标题显示「本机 N 个技能」，再点回会话正常

## 2. 主流程走查（好不好用）

- [ ] 「已安装」页签以卡片列出 `~/.dsh/skills` 与 `~/.agents/skills` 下的技能（应能看到 `stable-delivery-workflow` 与若干 dingtalk 技能），缩放窗口时一行依次为 4 / 3 / 2 / 1 张卡片
- [ ] 「全部」筛选下，用户级技能排在全局 agents 技能之前；单卡显示名称、卸载按钮、版本/来源/目录徽标、描述、路径与文件数
- [ ] 顶部筛选框输入关键字能实时过滤；「全部 / 用户级 / 全局 agents」切换正确
- [ ] 页面右上角「安装到」默认「用户级」；切到「全局 agents」后安装，技能写入 `~/.agents/skills`（卡片路径可见），提示语包含目标目录
- [ ] SkillHub 页签搜索 `pdf` 有结果卡片，点「安装」→ 按钮变「安装中…」→ 提示"已安装"→ 已安装卡片区出现该技能
- [ ] SkillsMP 页签搜索 `pdf` 有结果卡片，安装成功（匿名额度内）
- [ ] GitHub 页签输入 `anthropics/skills` → 搜索 → 列出 20 个技能 → 安装其中一个成功
- [ ] GitHub 页签只输入 skill 名称（如 `pdf`）→ 按名称返回卡片；无 Token 时显示"使用 SkillsMP 索引"的说明
- [ ] GitHub 卡片对带 Release 的仓库（如 `vercel-labs/agent-skills`）显示 `Release #xxxxxxx` 徽标，悬停可见完整 tag；无 Release 的仓库不显示
- [ ] 卸载：点「卸载」弹出确认框（显示名称与路径），点「取消」不删除；点「删除」后目录消失、列表移除

## 3. 边界与异常（稳不稳）

- [ ] SkillsMP 页签空关键词点搜索 → 提示"请先输入关键词"
- [ ] GitHub 页签输入 `not a repo` → 提示仓库格式不正确
- [ ] GitHub 页签输入不存在的仓库 → 提示仓库可能不存在/私有/分支不同
- [ ] 同名技能重复安装 → 弹出「已存在」确认，选覆盖后内容替换成功
- [ ] 断网或接口异常时页面给出可读提示，不白屏、不卡死
- [ ] 「设置」页填 GitHub Token 保存后显示「已配置」；点「清除」恢复「未配置」
- [ ] 「设置」页两个字段旁的 **说明** 点击展开（显示用途 / 获取 / 额度 / 安全），再点收起；展开时输入框下移、不遮挡内容；文案与 `docs/credentials.md` 第 6 节一致
- [ ] README 的「配置凭证」与「文档」两处链接都能打开 `docs/credentials.md`
